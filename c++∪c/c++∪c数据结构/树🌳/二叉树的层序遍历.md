# 一、什么是层序遍历

一句话：

👉 **一层一层，从上到下，从左到右遍历**

例如这棵树：

        A  
       / \  
      B   C  
     / \   \  
    D   E   F

层序遍历结果是：

A → B → C → D → E → F

---

# 二、核心思想（非常重要）

层序遍历的本质是：

👉 **用队列（Queue）来实现**

---

## 为什么用队列？

因为队列是：

先进先出（FIFO）

刚好符合：

一层一层按顺序访问

---

# 三、遍历步骤（一定要记住）

### 1️⃣ 根节点入队

队列：A

---

### 2️⃣ 循环直到队列为空

每次做三件事：

#### （1）取出队头节点

访问它（输出）

#### （2）把它的左孩子入队

#### （3）把它的右孩子入队

---

# 五、C语言代码（简单版）

```
#include <stdio.h>  
#include <stdlib.h>  
  
typedef struct Node  
{  
    char data;  
    struct Node *left;  
    struct Node *right;  
} Node;  
  
/* 创建节点 */  
Node* createNode(char x)  
{  
    Node* node = (Node*)malloc(sizeof(Node));  
    node->data = x;  
    node->left = NULL;  
    node->right = NULL;  
    return node;  
}  
  
/* 简单队列（数组实现） */  
Node* queue[100];  
int front = 0, rear = 0;  
  
/* 入队 */  
void enqueue(Node* x)  
{  
    queue[rear++] = x;  
}  
  
/* 出队 */  
Node* dequeue()  
{  
    return queue[front++];  
}  
  
/* 判断队列是否为空 */  
int isEmpty()  
{  
    return front == rear;  
}  
  
/* 层序遍历 */  
void levelOrder(Node* root)  
{  
    if (root == NULL)  
        return;  
  
    enqueue(root);  
  
    while (!isEmpty())  
    {  
        Node* p = dequeue();  
        printf("%c ", p->data);  
  
        if (p->left != NULL)  
            enqueue(p->left);  
  
        if (p->right != NULL)  
            enqueue(p->right);  
    }  
}  
  
/* 测试 */  
int main()  
{  
    Node* A = createNode('A');  
    Node* B = createNode('B');  
    Node* C = createNode('C');  
    Node* D = createNode('D');  
    Node* E = createNode('E');  
    Node* F = createNode('F');  
  
    A->left = B;  
    A->right = C;  
    B->left = D;  
    B->right = E;  
    C->right = F;  
  
    printf("层序遍历结果：");  
    levelOrder(A);  
  
    return 0;  
}
```

# 六、一定要记住的本质

层序遍历 =

队列 + 每次取一个节点 + 把它的孩子放进去

---

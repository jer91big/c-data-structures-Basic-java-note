# 平衡二叉树
## 一句话总结

**就是不会长歪的二叉排序树**，在二叉排序树基础上，多了**平衡限制**。

## 核心定义

1. 首先**必须是二叉排序树**（满足左小右大）
2. 每个节点的**左右子树高度差绝对值 ≤ 1**
    
    这个高度差叫**平衡因子**，只能是：**-1、0、1**

## 解决了什么问题

普通二叉排序树最坏会变成一条链表（1→2→3→4），查找变慢；

**平衡二叉树强制不让树长高、长歪**，始终保持左右差不多一样高。

## 平衡因子

平衡因子 = 左子树高度 − 右子树高度

只能取：**-1、0、1**，超出就要**旋转调整**。

## 失衡怎么修（四种旋转）

1. **LL 左左**：右旋
2. **RR 右右**：左旋
3. **LR 左右**：先左旋再右旋
4. **RL 右左**：先右旋再左旋

## 特点

- 严格平衡，**查找效率稳定 O (logn)**
- 插入删除麻烦，要算高度、判平衡、做旋转
- 考试常考：求平衡因子、判断失衡类型、画旋转后的树

## 最简区分

- **二叉排序树 BST**：只守「左小右大」，可以歪成链
- **平衡二叉树 AVL**：既要左小右大，又要左右高度差不多，歪了就旋转掰正
# 平衡二叉树的调整
前提：

- 是**二叉排序树**
- 平衡因子差超 1 就失衡，分**LL、RR、LR、RL**四种，只用**左旋、右旋**两种操作。

## 一、两个基础旋转

### 1. 右旋（LL 专用）

场景：**左子树的左子树太重**（左左）

操作：

1. 把**根的左孩子**提上来当新根
2. 新根的右子树，挂回旧根的左孩子
    
    口诀：**右歪向右掰，LL 一次右旋**

### 2. 左旋（RR 专用）

场景：**右子树的右子树太重**（右右）

操作：

1. 把**根的右孩子**提上来当新根
2. 新根的左子树，挂回旧根的右孩子
    
    口诀：**左歪向左掰，RR 一次左旋**

---

## 二、四种失衡类型及调整方法

### 1. LL 型（左左失衡）

**特征**：新节点插在 **左子树的左下方**

**调整**：直接 **单次右旋**

### 2. RR 型（右右失衡）

**特征**：新节点插在 **右子树的右下方**

**调整**：直接 **单次左旋**

### 3. LR 型（左右失衡）

**特征**：新节点插在 **左子树的右下方**

**调整**：分两步

1. 先对左子树 **左旋**
2. 再对根 **右旋**
    
    口诀：**先左后右**

### 4. RL 型（右左失衡）

**特征**：新节点插在 **右子树的左下方**

**调整**：分两步

1. 先对右子树 **右旋**
2. 再对根 **左旋**
    
    口诀：**先右后左**

---

## 三、万能记忆口诀

> **LL 右旋，RR 左旋**
> 
> **LR 先左后右，RL 先右后左**

## 四、核心规律

- 同侧（LL、RR）：**一次单旋转**
- 异侧（LR、RL）：**两次双旋转**

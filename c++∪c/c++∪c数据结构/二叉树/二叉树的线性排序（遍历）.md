# 一、DFS（三种）⭐⭐⭐

---

## 1️⃣ 先序遍历（Preorder）

### 规则

根 → 左 → 右

### 递归代码
```

`void PreOrder(TreeNode *T){`

    `if(T == NULL) return;`

    `printf("%d ", T->data);`

    `PreOrder(T->lchild);`

    `PreOrder(T->rchild);`

`}`
```

---

## 2️⃣ 中序遍历（Inorder）⭐⭐⭐

### 规则

左 → 根 → 右

### 重点

- 二叉排序树中 → 中序 = 有序序列
    
- 线索二叉树基础
    

### 递归代码
```

void InOrder(TreeNode *T){

    if(T == NULL) return;

    InOrder(T->lchild);

    printf("%d ", T->data);

    InOrder(T->rchild);

}
```

---

## 3️⃣ 后序遍历（Postorder）

### 规则

左 → 右 → 根

### 应用

- 删除二叉树
    
- 表达式求值
    

### 递归代码
```

void PostOrder(TreeNode *T){

    if(T == NULL) return;

    PostOrder(T->lchild);

    PostOrder(T->rchild);

    printf("%d ", T->data);

}

```

# 二、层序遍历（BFS）⭐⭐⭐

> 必须使用队列

### 思想

1. 根入队

2. 出队访问

3. 左孩子入队

4. 右孩子入队

### 代码

```
void LevelOrder(TreeNode *T){

    if(T == NULL) return;

  

    Queue Q;

    InitQueue(&Q);

    EnQueue(&Q, T);

  

    while(!IsEmpty(Q)){

        TreeNode *p;

        DeQueue(&Q, &p);

        printf("%d ", p->data);

  

        if(p->lchild) EnQueue(&Q, p->lchild);

        if(p->rchild) EnQueue(&Q, p->rchild);

    }

}

```

# 三、必考总结 ⭐⭐⭐

### 1️⃣ 时间复杂度

O(n)

### 2️⃣ 空间复杂度

O(h)   （h为树高）

### 3️⃣ 唯一性

- 先序 + 中序 → 唯一确定
    
- 后序 + 中序 → 唯一确定
    
- 先序 + 后序 → ❌ 不一定唯一
    

---

# 四、记忆核心

- 先序：根最先
    
- 中序：BST 得有序
    
- 后序：根最后
    
- 层序：用队列

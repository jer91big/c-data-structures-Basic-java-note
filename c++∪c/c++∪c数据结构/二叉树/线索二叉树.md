# 一、基本概念

## 1️⃣ 前驱 / 后继

在某种遍历序列中：

- 前驱：当前结点之前的结点
    
- 后继：当前结点之后的结点
    

⚠ 是遍历顺序关系，不是父子关系

---

## 2️⃣ 线索规则（中序）⭐

- 左孩子为空 → 指向**中序前驱**
    
- 右孩子为空 → 指向**中序后继**
    

---

# 二、结点结构 ⭐⭐⭐

```
typedef struct ThreadNode{

    int data;

    struct ThreadNode *lchild, *rchild;

    int ltag, rtag;

}ThreadNode;

```
### 标志位含义

- `ltag = 0` → 左孩子
    
- `ltag = 1` → 前驱
    
- `rtag = 0` → 右孩子
    
- `rtag = 1` → 后继
    

---

# 三、中序线索化 ⭐⭐⭐

> 本质 = 中序遍历 + 记录前驱结点

关键指针：
**==无左连前驱**==
==**无右连后继**==
==**pre 记录前一个访问节点==**
```

ThreadNode *pre = NULL;
```

---

## 线索化代码模板

```
void InThread(ThreadNode *T){

    if(T == NULL) return;

  

    InThread(T->lchild);

  

    // 处理当前结点

    if(T->lchild == NULL){

        T->lchild = pre;

        T->ltag = 1;

    }

  

    if(pre != NULL && pre->rchild == NULL){

        pre->rchild = T;

        pre->rtag = 1;

    }

  

    pre = T;

  

    InThread(T->rchild);

}

```

# 四、中序遍历（非递归）⭐⭐⭐

---
**==先找最左节点**==
==**如果是线索 → 直接走**==
==**如果是右子树 → 找右子树最左==**
## 1️⃣ 找第一个结点
```

ThreadNode* FirstNode(ThreadNode *T){

    while(T->ltag == 0)

        T = T->lchild;

    return T;

}
```

---

## 2️⃣ 找后继
```

ThreadNode* NextNode(ThreadNode *T){

    if(T->rtag == 0)

        return FirstNode(T->rchild);

    else

        return T->rchild;

}

```
---

## 3️⃣ 中序遍历算法

```
void InOrder(ThreadNode *T){

    for(ThreadNode *p = FirstNode(T); 

        p != NULL; 

        p = NextNode(p))

        printf("%d ", p->data);

}

```

# 五、时间复杂度

线索化：

O(n)

O(n)

空间复杂度：

O(h)   （h为树高）

# 六、核心记忆 ⭐⭐⭐

- 线索 = 遍历序列邻接关系
    
- 必须设置 `ltag / rtag`
    
- 中序线索最重要
    
- 线索化 = 中序遍历 + pre 指针
    
- 可实现无递归遍历

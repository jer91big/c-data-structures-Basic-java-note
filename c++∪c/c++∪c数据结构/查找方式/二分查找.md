### 🥷 下一个 Boss：二分查找（Binary Search）

既然你已经掌握了如何让数组变得“有序”，那我们绝不能浪费这个特性。在有序数组里找东西，如果我们还用挨个查看的“笨办法”，那就太对不起刚刚辛苦跑完的排序算法了。

这时候，我们要请出算法界的“瞬移大师”——**二分查找**。

#### 🎬 动画演示：猜数字游戏

想象你在玩一个猜数字游戏：我心里想一个 **1 到 100** 之间的数字，你来猜。

- **普通人的做法**：1？不是。2？不是。3？……（这叫线性查找，最坏要猜 100 次）。
    
- **二分查找的做法**：
    
    1. **劈一半**：“50！”
        
    2. **看提示**：我说“太小了”。
        
    3. **再劈一半**：既然 1-50 都小了，那你直接看 51-100 的中间——“75！”
        
    4. **看提示**：我说“太大了”。
        
    5. **再劈一半**：在 51-74 之间再砍一刀……
        

**结果**：哪怕是 1 到 40 亿个数字，二分查找也只需要最多 **32 次** 就能抓到那个数！

#### 📍 核心逻辑：两个边界，一个中心

1. **左边界 (L)** 指向开头，**右边界 (R)** 指向结尾。
    
2. 计算 **中间点 (Mid)**。
    
3. 如果 `Mid` 对应的值**大了**，就把右边界拉过来：`R = Mid - 1`。
    
4. 如果 `Mid` 对应的值**小了**，就把左边界推过去：`L = Mid + 1`。
    
5. 如果正合适，恭喜你，抓住了！

### 🧪 练手小题：逻辑推演

假设现在有一个排好序的数组：`[1, 3, 5, 7, 9, 11, 13]`

我们要找数字 **3**。

1. 第一轮：`L=0, R=6`，`Mid` 是谁？对应的值是多少？
    
2. 接下来 `L` 或 `R` 会如何移动？
## 完整代码//包含归并排序
```
#include <functional>

#include<iostream>

#include <memory>

#include<vector>

using namespace std;

int merge(vector<int>&arr,int left,int mid,int right)

{

    int i=left,j=mid+1,k=0;

    int count=0;

    vector<int>temp(right-left+1);

    while(i<=mid&&j<=right)

    {

        if(arr[i]<=arr[j])

        {

            temp[k]=arr[i];

            i++;

            k++;

        }

        else {

            temp[k]=arr[j];

            j++;

            k++;

            count+=mid-i+1;

        }

    }

    while(i<=mid)

    {

        temp[k]=arr[i];

        i++;

        k++;

    }

    while(j<=right)

    {

        temp[k]=arr[j];

        j++;

        k++;

    }

    for(int i=0;i<temp.size();i++)

    {

        arr[left+i]=temp[i];

    }

    return count;

  

}

  

int mergeSort(vector<int>&arr,int left,int right)

{

    int count=0;

    if(left<right)

    {

        int mid=left+(right-left)/2;

        count+=mergeSort(arr,left,mid);

        count+=mergeSort(arr,mid+1,right);

        count+=merge(arr,left,mid,right);

    }

    return count;

}

int binarysearch(vector<int>&arr,int left,int right,int target)//二分查找

{

    int mid=left+(right-left)/2;

  

    if(left <= right)

    {

        int mid = left + (right - left)/2;

        if(arr[mid] == target) // 修复：使用比较运算符，移除分号

        {

            return mid;

        }

        else if(arr[mid] > target)

        {

            return binarysearch(arr, left, mid-1, target); // 修复：在左半部分查找

        }

        else

        {

            return binarysearch(arr, mid+1, right, target); // 修复：在右半部分查找

        }

    }

    return -1; // 修复：确保函数总是有返回值

}

int main ()

{

    vector<int>arr={5,2,8,1,9,3,6};

    cout<<"Before sorting: ";

    for(int i=0;i<arr.size();i++)

    {

        cout<<arr[i]<<" ";

    }

    cout<<endl;

    int count=mergeSort(arr,0,arr.size()-1); //

    cout<<"After sorting: ";

    for(int i=0;i<arr.size();i++)

    {

        cout<<arr[i]<<" ";

    }

    cout<<endl;

    cout<<"逆序队数为"<<count<<endl;

    int index=binarysearch(arr,0,arr.size()-1,3);

    cout<<"3的索引为"<<index<<endl;

    return 0;

}
```

既然你要攻克的是**快速排序（Quick Sort）**，这位 Boss 在算法界被称为**“闪电侠”**，它的核心性格就是：**雷厉风行，左右分明**。

---

### 🎬 快速排序：大型“点将分兵”现场

想象你手里有一排乱七八糟的士兵，他们的身高（数字）参差不齐。你的目标是让他们按身高从矮到高排好队。

#### 📍 第一幕：点将（The Pivot）

你随手一指，点出了排在第一位的士兵。

> **“你，出列！从现在起，你就是‘临时队长’（基准点 Pivot）。”**
> 
> 这个队长往中间一站，成了整场戏的灵魂。他的任务很简单：把剩下的兄弟们按身高分成两拨。

#### 📍 第二幕：左右护法（The Partition）

这是最精彩的“乾坤大挪移”。

1. **左侦察兵（L）**：从最左边出发，往右跑。他的任务是找**比队长高**的人。
    
2. **右侦察兵（R）**：从最右边出发，往左跑。他的任务是找**比队长矮**的人。
    

当两个侦察兵都找到了目标，他们就喊：**“换！”**。于是，那个高个子和那个矮个子瞬间互换位置。

这个过程一直持续，直到两个侦察兵撞在一起。

#### 📍 第三幕：队长归位（The Reunion）

两个侦察兵会合的那一刻，队长（基准点）优雅地走过去，坐在他们会合的位置。

**高能瞬间：** 队长坐下后，你会惊讶地发现：

- 坐在队长**左边**的，全都是比他矮的；
    
- 坐在队长**右边**的，全都是比他高的。
    
    **虽然左右两边内部还是乱的，但队长自己已经找到了他在全宇宙中最终、最准确的位置！**
    

#### 📍 第四幕：子孙满堂（Recursion）

队长坐稳后，左边那群矮个子和右边那群高个子互相对视了一眼。

> **“兄弟们，我们也选个队长，按刚才的办法分！”**
> 
> 于是，左边选一个新队长，继续分；右边也选一个新队长，继续分……直到每支小队只剩下一个人。

---

### 🛡️ 为什么这个 Boss 很厉害？

- **它的战术：分而治之（Divide and Conquer）**。它不急着一次把全排排好，它只管找准一个人的位置，然后把问题拆成两个小麻烦，最后小麻烦全解决了，整个大队就整齐了。
    
- **它的速度**：平均时间复杂度是 $O(n \log n)$。在大多数情况下，它是所有通用排序算法里最快的那一个，名副其实。
    

---

### 🧠 脑海中需要留下的“画面”

1. **一个队长**（选定一个数）。
    
2. **两个哨兵互换**（左边找大的，右边找小的，互换）。
    
3. **一个分界线**（队长坐中间，从此两边不往来）。
## 完整代码
```
#include<iostream>
#include<vector>
using namespace std;
int partition(vector<int>&arr,int low,int high)
{
    int pivot=arr[low];
    int left=low;
    int right=high;
    while(left<right)
    {
        while(left<right&&arr[right]>=pivot)
        {
            right--;
        }
        while(left<right&&arr[left]<=pivot)
        {
            left++;
        }
        if(left<right)
        {
            swap(arr[left],arr[right]);
        }
    }
    swap(arr[low],arr[left]);
    return left;
}
void quickSort(vector<int>&arr,int low,int high)
{
    if(low<high)
    {
        int pivot=partition(arr,low,high);
        quickSort(arr,low,pivot-1);
        quickSort(arr,pivot+1,high);
    
    }
}
int main()
{
    vector<int>arr={5,2,8,1,9,53,6,7};
    cout<<"-----------------";
    for(int x:arr) cout<<x<<" ";
    cout<<endl;
    cout<<"-----------------"<<endl;
    cout<<"开始闪电排序"<<endl;
    quickSort(arr,0,arr.size()-1);
    for(int i=0;i<arr.size();i++)
    {
        cout<<arr[i]<<" ";
    }
    return 0;
}
```

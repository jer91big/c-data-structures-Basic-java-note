按照我们的约定，在打下一个 Boss 之前，我绝不直接糊代码。我们要先看“电影”。

现在，有请排序界的第二位大魔王、以“稳如老狗”著称的——**归并排序（Merge Sort）**。如果说快速排序是“点将分兵”，那么归并排序的绝招就是**“碎裂与拉链”**。

### 🎬 归并排序：大型“碎裂与重组”现场

想象你手里有一副完全洗乱的扑克牌。归并排序的指挥官根本不屑于在乱牌里找什么“队长”，他的战术极其粗暴且优雅。

#### 📍 第一幕：无限碎裂（Divide）

指挥官拿起这叠牌，**“唰”地一下从中间撕成两半**。

> “左边一半，右边一半。还乱吗？乱！继续撕！”

他又把这两半各自撕成两半……就这么一直撕下去。 **直到最后，所有的牌都变成了单独的一张张牌。** 这时候，指挥官笑了：“一张牌，算不算排好序了？当然算！”

#### 📍 第二幕：拉链对决（The Merge）

现在桌子上全是排好序的“单张牌”。指挥官开始下令**合并**。

假设左边小队是 `[2, 5, 8]`（已经内部排好序了），右边小队是 `[1, 3, 9]`（也排好序了）。 现在的任务是：把他们合并成一个 `[1, 2, 3, 5, 8, 9]` 的大队。

指挥官的“拉链法”是这样操作的：

1. **各派代表**：左边最前面的 `2` 出列，右边最前面的 `1` 出列。
    
2. **擂台 PK**：`2` 和 `1` 比大小。**`1` 更小，`1` 胜出！** `1` 走到新队伍的第一个位置坐下。
    
3. **替补跟上**：右边小队失去了 `1`，第二名的 `3` 赶紧补上，站到最前面。
    
4. **再次 PK**：现在是左边的 `2` 对战右边的 `3`。**`2` 更小，`2` 胜出！** `2` 走到新队伍的第二个位置。
    
5. **不断循环**：就像拉衣服上的拉链一样，左右两边依次派出最前面的人比较，谁小谁就“咬合”进去。
    

#### 📍 第三幕：天下归一

这种“拉链式”的合并，从单张牌合并成两张、两张合并成四张……一路往上合，直到最后左右两支半数的大军完成最后一次惊天动地的“大拉链合并”，全军排序完成！

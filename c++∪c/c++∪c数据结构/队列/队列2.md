## 四、优先队列最常用的 3 种用法（直接背这三个）

### 1. 默认：大顶堆（最大值优先）

cpp

运行

```
```
#include <iostream>
#include <queue>
using namespace std;

int main() {
    priority_queue<int> pq;  // 大顶堆

    // 插入元素
    pq.push(3);
    pq.push(1);
    pq.push(5);
    pq.push(2);

    // 输出：5 3 2 1（从大到小）
    while (!pq.empty()) {
        cout << pq.top() << " ";
        pq.pop();
    }
}
```
```

---

### 2. 小顶堆（最小值优先）

刷题**最常用**！

cpp

运行

```
priority_queue<int, vector<int>, greater<int>> pq;
```

插入 3,1,5,2 → 输出：**1 2 3 5**

### 3. 存结构体 / 自定义排序（比如存节点）

cpp

运行

```
struct Node {
    int val;
    bool operator<(const Node& other) const {
        return val < other.val; // 大顶堆
    }
};
```

**队列（Queue）**是一种**线性数据结构**，特点是：

> **先进先出（FIFO，First In First Out）**

就像**排队买东西**一样：

- 先来的人先走
    
- 后来的人只能排在后面
    

---

# 一、队列示意图

入队 → → → → → → → → 出队  
  
      ┌────┬────┬────┬────┐  
      │ A  │ B  │ C  │ D  │  
      └────┴────┴────┴────┘  
        ↑                ↑  
      队头             队尾  
     (Front)          (Rear)

操作规则：

|操作|含义|
|---|---|
|入队 (EnQueue)|从 **队尾** 插入元素|
|出队 (DeQueue)|从 **队头** 删除元素|

例子：

队列开始：空  
  
入队 A → A  
入队 B → A B  
入队 C → A B C  
  
出队 → 删除 A  
剩下 → B C

# 三、队列的顺序存储（数组实现）

结构：

队列数组：  
  
 index  
 0   1   2   3   4  
┌───┬───┬───┬───┬───┐  
│ A │ B │ C │   │   │  
└───┴───┴───┴───┴───┘  
 ↑           ↑  
front       rear

C语言结构：

```
#define MAXSIZE 100  
  
typedef struct{  
    int data[MAXSIZE];  
    int front;  
    int rear;  
}SqQueue;
```

初始化：

Q.front = Q.rear = 0;

# 四、循环队列（最重要）

普通顺序队列会出现问题：

出队后前面空间浪费

解决方法：**循环队列**

数组首尾连接成环

示意：

      ┌───┐  
   ┌──┘   └──┐  
┌──┴──┬──┬──┬──┐  
│ A   │B │C │  │  
└─────┴──┴──┴──┘

关键公式：

### 入队

```
rear = (rear + 1) % MaxSize

```
### 出队

```
front = (front + 1) % MaxSize
```

### 判断队满

```
(rear + 1) % MaxSize == front
```

### 判断队空

rear == front

# 五、链式队列（链表实现）

结构：

front → A → B → C → D → NULL  
                        ↑  
                       rear

结构体：

```
typedef struct Node{  
    int data;  
    struct Node *next;  
}Node;  
  
typedef struct{  
    Node *front;  
    Node *rear;  
}LinkQueue;

```
优点：

- 不会溢出（除非内存满）
    
- 动态分配空间

# 七、和栈的区别（考试常考）

|数据结构|特点|
|---|---|
|栈|**后进先出 LIFO**|
|队列|**先进先出 FIFO**|

示意：

栈：

进 → A B C  
出 → C B A

队列：

进 → A B C  
出 → A B C

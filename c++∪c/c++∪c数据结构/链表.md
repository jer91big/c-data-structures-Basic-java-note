# 单向链表
- 每个节点只有**一个指针域**，仅指向**下一个节点**，无法反向遍历（只能从`head`从头走到尾）。
1. 
创建链表
```
typedef struct node
{
	int data;
	node* next;
}node;
```
2. 
初始化链表
```
node* initlist()
{
	node *head=new node;
	head->data=0;
	head->next=NULL;
	return head;
}
```
3. 
 插入数据
 [ 1] 头插法
```
void inserthead(node *l,int e)//头插法 
{
	node *p=new node;
	p->data=e;
	p->next=l->next;
	l->next=p;
}//插入到第一个元素
```
[2]尾插法
```
void inserttail(node *l,int n)//尾插法 
{
	node *p=new node;
	p->data=n;
	p->next=nullptr;
	node *tail=l;
	while(tail->next!=nullptr){
		tail=tail->next;
		//遍历到最后一个数据
	}
```

6. 移除相同的元素//思路奇特//有难度
```
void removethesame(node *l,int n) //移除相同的数据 
{
	node *p=l;
	int index;
	
	int *q=(int*)malloc(sizeof(int)*(n+1));
	for(int i=0;i<=n+1;i++){
		*(q+i)=0;
	}
	while(p->next!=NULL){
		index=abs(p->next->data);
		if(*(q+index)==0){
			*(q+index)=1;
			p=p->next;
		}
		else{
			node*temp=p->next;
			p->next=temp->next;
			free(temp);
		}
		
		
	}
	free(q);
}
```
7. 反转链表//有难度
```
node* reversal(node *head) //反转 
{
	node *first=nullptr;
	node *second=head->next;
	node *third=nullptr;
	
	while(second!=nullptr){
		third=second->next;
		second->next=first;
		first=second;
		second=third;
	}
	head->next=first;
	return head;
	
}
```
# 双向链表
-  每个节点有**两个指针域**：`prev`（指向前一个 / 前驱节点）、`next`（指向后一个 / 后继节点），还有一个数据域存储有效数据。
 - 头节点的`prev`为`nullptr`，尾节点的`next`为`nullptr`，形成清晰的链表边界。
 - 支持**双向遍历**：既可以从头节点`head`遍历到尾节点，也可以从尾节点`tail`反向遍历到头节点，灵活性远高于单向链表。
- 操作效率：头部 / 尾部操作（头插、头删、尾插、尾删）均为`O(1)`（因为维护了尾节点`tail`，无需像单向链表尾插那样遍历）；中间插入 / 删除效率仍为`O(n)`（需要先找到目标节点），但找到目标节点后，修改指针的逻辑比单向链表稍复杂（要同时维护`prev`和`next`）。
1. 创建链表
```
  typedef struct node
{
	node *pre; 
	int data;
	node* next;
}node;
```
2. 初始化链表
```
node *initlist()
{
	node *head=new node;
	head->data=0;
	head->next=nullptr;
	head->pre=nullptr;
	return head;
}
```
3. 插入数据
- 1头插法
```
void inserthead(node *l,int val)//头插法 
{
	node *p=new node;
	p->data=val;
	p->pre=l;
	p->next=l->next;
	if(l->next!=nullptr)
	l->next->pre=p;
	l->next=p;
} 
```

```
void inserttail(node *l,int val)//尾插法 
{
	node *p=new node;
	p->data=val;
	p->next=nullptr;
	p->pre=nullptr;
	node *tail=l;
	while(tail->next!=nullptr){
		tail=tail->next;//TODO
	}
	p->pre=tail;
	tail->next=p;
	p->next=nullptr;
	
} 
```
4. 链表中插入数据
```
void midinsert(node *l,int position,int val)//插入数据 
{
    int i=0;
    node *p=new node;
    while(i<position-1){
	    l=l->next;
	    i++;
	}
	p->data=val;
	p->pre=l;
	p->next=l->next;
	l->next=p;
	
}
```

```
void deletenum(node *l,int position)
```

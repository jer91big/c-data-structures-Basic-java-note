# C++ 中的向量（vector）

在 C++ 里，**`std::vector`** 是最常用、最实用的**动态数组**（可以自动扩容的数组），属于标准库容器，用起来比普通数组方便太多。

我用最通俗、最实用的方式给你讲清楚👇

---

## 1. 什么是 vector？

- 它是**动态数组**：大小可以随时变，不用提前固定长度
- 存放在**堆内存**，自动管理内存，不会内存泄漏
- 支持**随机访问**（像数组一样用 `[]` 访问元素）
- 尾部添加 / 删除元素**非常快**

一句话：**比普通数组更安全、更灵活、更好用。**

---

## 2. 必须包含的头文件

cpp

运行

```
#include <vector>   // 必须加
using namespace std; // 方便写 vector 而不是 std::vector
```

---

## 3. 最常用的定义方式

cpp

运行

```
// 1. 空向量
vector<int> v1;

// 2. 初始大小为 5，默认值都是 0
vector<int> v2(5);

// 3. 大小为 5，每个元素都是 10
vector<int> v3(5, 10);

// 4. 直接初始化（C++11 及以上）
vector<int> v4 = {1, 2, 3, 4, 5};
```

---

## 4. 最常用操作（必背）

### ① 添加元素（尾部）

cpp

运行

```
v.push_back(6);  // 往最后加一个元素
```

### ② 访问元素

cpp

运行

```
// 方法1：像数组一样（快，但越界会崩溃）
int x = v[0];

// 方法2：at()（会检查越界，更安全）
int y = v.at(1);
```

### ③ 获取大小 & 判断空

cpp

运行

```
v.size();      // 元素个数
v.empty();     // 是否为空（空返回 true）
v.capacity();  // 容量（实际分配的内存）
```

### ④ 删除元素

cpp

运行

```
v.pop_back();        // 删除最后一个
v.clear();           // 清空所有
v.erase(v.begin() + 2); // 删除第 3 个元素（索引 2）
```

### ⑤ 遍历 vector

cpp

运行

```
// 方法1：普通 for
for(int i=0; i<v.size(); i++)
    cout << v[i] << endl;

// 方法2：范围 for（最简洁）
for(int num : v)
    cout << num << endl;
```

---

## 5. 完整示例（可直接运行）

cpp

运行

```
#include <iostream>
#include <vector>
using namespace std;

int main() {
    // 创建向量
    vector<int> v = {10, 20, 30};

    // 添加元素
    v.push_back(40);
    v.push_back(50);

    // 输出大小
    cout << "大小：" << v.size() << endl;

    // 遍历
    for (int n : v) {
        cout << n << " ";
    }

    // 删除最后一个
    v.pop_back();

    return 0;
}
```

---

## 6. vector 优点总结

✅ 自动扩容，不用手动管理内存

✅ 支持随机访问 `O(1)`

✅ 尾部增删极快 `O(1)`

✅ 语法简洁，代码安全

✅ 几乎可以替代所有普通数组

---

## 7. 常见使用场景

- 存**不确定数量**的数据
- 代替普通数组
- 函数返回多个值
- 临时存储数据列表

---

### 总结

- **vector = 动态数组**
- 用 `push_back()` 添加、`[]` 访问、`size()` 看大小
- 比普通数组**安全、方便、强大**
- 日常写 C++ 优先用 `vector`，少用普通数组

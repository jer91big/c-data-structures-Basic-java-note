## 🔌 最后一块拼图：接口 (Interface) —— 终极“能力契约”

上一课咱们讲了，抽象类依然是个“类”（只能单继承，只能认一个爹）。

但现实开发中，**“亲爹”只有一个，能耐却可以有成百上千个**。

这就是**接口**诞生的原因：它不关心你的血统（你是谁），只关心你的能力（你会干啥）。

## 🛠️ 1. 抽象类 vs 接口（动画极速对比）

> **动画演示：**
> 
> - **继承抽象类（认爹）：** 蝙蝠 `extends` 飞禽类。蝙蝠说：“我体内流着飞禽类的血！”（**血统/身份**，`is-a` 关系）。
>     
> - **实现接口（领技能证）：** 飞机、蝙蝠、超人，都挂着一个 **`Flyable`（会飞）** 的能力勋章。只要领了这个勋章，不管你是什么东西，你都必须能飞！（**能力/行为**，`like-a` 或 `has-a` 关系）。
>     

## 📜 2. 怎么写接口？

用 `interface` 替代 `class`，用 `implements`（实现）替代 `extends`（继承）。

### 第一步：定义接口（纯粹的规范）

在 Java 8/9 以前，接口极其纯粹：**里面只能有“全局常量”和“抽象方法”**（连普通变量都不允许有）。

Java

```
public interface Flyable {
    // 接口里的方法默认都是 public abstract（可以省略不写）
    void fly(); 
}
```

### 第二步：类来实现接口（领证并练功）

Java

```
// 超人：继承了“人类”，同时领了“会飞”的技能证
public class Superman extends Human implements Flyable {

    // 必须重写接口里的抽象方法！
    @Override
    public void fly() {
        System.out.println("超人穿上红斗篷，呼啸着飞向天空！");
    }
}
```

## ⚡ 3. 接口的 3 大无敌特性

### ① 多实现（撕破单继承的枷锁！）

一个类**只能继承一个父类**，但可以**同时实现无数个接口**！用逗号隔开：

Java

```
public class SteelMan implements Flyable, Chargeable, Attackable {
    // 钢铁侠同时拥有：会飞、能充电、能攻击 3 种能力！
    // 必须把这 3 个接口里的所有抽象方法全写了！
}
```

### ② 接口之间可以“多继承”

接口和接口之间可以用 `extends`，而且**支持多继承**！

Java

```
// “超级英雄”接口，同时继承了“会飞”和“攻击”两个接口
public interface SuperHero extends Flyable, Attackable {
    // 谁要是实现 SuperHero，就必须把飞和攻击的方法全都实现了
}
```

### ③ 极其完美的“多态”

接口最香的地方，依然是配合多态使用。

Java

```
// 只要领了 Flyable 证的东西，统统可以传进来飞一圈！
public void makeItFly(Flyable f) {
    f.fly(); // 编译器只认接口，运行时各显神通
}

// 传超人、传飞机、传大雁，全都没问题！
makeItFly(new Superman());
makeItFly(new Airplane());
```

## 💡 知识汇总表：抽象类 vs 接口（面试必背）

| **维度**   | **抽象类 (abstract class)** | **接口 (interface)**             |
| -------- | ------------------------ | ------------------------------ |
| **定位**   | 模型的抽取（强调**身份/血统**）       | 功能的抽取（强调**能力/规范**）             |
| **继承数量** | 一个类只能继承 **1** 个抽象类       | 一个类可以实现 **无数** 个接口             |
| **成员变量** | 随便写（普通变量、常量都可以）          | 只能是 public static final **常量** |
| **构造器**  | **有**构造器（给子类初始化用）        | **绝对没有**构造器                    |
| **设计逻辑** | `is-a`（猫**是**一种动物）       | `has-a` / `can-do`（飞机**能**飞）   |

## 🏠 1. 为什么要用内部类？（寄生与滋养）

想象一下：你的手机（外部类）里面有一块电池（内部类）。

- 电池离开手机单独存在没有意义。
    
- 但电池需要直接读取手机的状态（比如剩余电量、温度），手机也需要随时控制电池。
    

**内部类的核心特点：**

1. **天然拥有特权**：内部类可以直接无条件访问外部类的**私有属性（`private`）**！
    
2. **良好的封装**：如果你写了一个类，只想给某一个特定的类使用，不希望外界知道它的存在，就把它藏在里面。
    

## 🗂️ 2. 内部类的 4 大家族成员

Java 里一共有 4 种内部类，咱们用“在房间里放东西”来做比喻：

### ① 成员内部类（最普通的“房间小隔间”）

直接写在类里面、方法外面，就像外部类的一个普通的“成员变量”。

Java

```
public class Outer {
    private String secret = "外部类的私有秘密";

    // 1. 成员内部类
    public class Inner {
        public void show() {
            // 直接访问外部类的私有变量！
            System.out.println("内部类读取到的秘密：" + secret);
        }
    }
}
```

> **创建它的语法（有点别扭）：**
> 
> 必须先有外部类对象，才能创建内部类对象。
> 
> `Outer outer = new Outer();`
> 
> `Outer.Inner inner = outer.new Inner();`

### ② 静态内部类（用 `static` 修饰的“独立套间”）

被 `static` 修饰的内部类。它不再依赖外部类的具体对象，自己就能独立存在。

Java

```
public class Outer {
    private static String count = "100";

    // 2. 静态内部类
    public static class StaticInner {
        public void show() {
            // 只能访问外部类的 static 属性！
            System.out.println(count);
        }
    }
}
```

> **创建它的语法（很直接）：**
> 
> `Outer.StaticInner inner = new Outer.StaticInner();`

### ③ 局部内部类（写在方法里的“临时折叠床”）

定义在某个**方法内部**的类。生命周期极短，方法执行完了，这个类也就没用了。开发中极少使用。

Java

```
public class Outer {
    public void testMethod() {
        // 3. 局部内部类（只在这个方法里有效）
        class LocalInner {
            public void run() {
                System.out.println("我是临时工...");
            }
        }
        LocalInner local = new LocalInner();
        local.run();
    }
}
```

### ④ 匿名内部类（💥 绝对的核心！日常开发90%用的都是它）

当你只需要用一次某个接口或抽象类的实现对象，**连给这个类起名字都懒得起**的时候，直接用**匿名内部类**。

> **动画演示：**
> 
> 1. 你手里有一个接口 `interface ButtonClickListener { void onClick(); }`。
>     
> 2. 传统做法：写一个 `MyListener` 类去实现接口，然后 `new MyListener()`。
>     
> 3. **匿名内部类做法**：现场抛出一个“无名大招”，边定义类、边实现接口、边 `new` 出对象！
>     

Java

```
// 假设有一个接口
interface Playable {
    void play();
}

public class Main {
    public static void main(String[] args) {
        
        // 4. 匿名内部类：没有类名，直接 new 接口并在大括号里实现方法！
        Playable p = new Playable() {
            @Override
            public void play() {
                System.out.println("临时播放音乐...");
            }
        };

        p.play(); // 调用方法
    }
}
```

## ⚡ 总结与对比表

|**内部类类型**|**定义位置**|**访问外部类权限**|**创建方式**|**常用程度**|
|---|---|---|---|---|
|**成员内部类**|类中方法外|可直接访问外部类**所有**成员|`outer.new Inner()`|⭐⭐|
|**静态内部类**|类中方法外（加 static）|只能访问外部类 **static** 成员|`new Outer.Inner()`|⭐⭐⭐|
|**局部内部类**|方法内部|能访问外部类及方法内的局部变量|只能在方法内 `new`|⭐|
|**匿名内部类**|任意需要用对象的地方|取决于所在的上下文|`new 接口/父类(){ 重写方法 }`|⭐⭐⭐⭐⭐|

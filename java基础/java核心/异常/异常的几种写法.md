### 写法 1：try + catch + finally（刚才的例子）

```
try {
    //危险代码
} catch (异常类型 e) {
    //处理异常
} finally {
    //必执行
}
```

### 写法 2：try + catch（没有 finally，不需要释放资源）

```
try {
    int a = 1/0;
} catch (ArithmeticException e) {
    System.out.println("除零异常");
}
```

### 写法 3：try + finally（没有 catch，不捕获，异常继续往上抛，但资源要关闭）

```
try {
    int a = 1/0;
} finally {
    System.out.println("我一定会执行");
}
```

> 这里异常没被捕获，程序最后还是会崩溃，但 finally 先跑。

### 写法 4：try-with-resources（处理资源，自动 close）

```
try(FileReader fr = new FileReader("a.txt")){
    fr.read();
}catch (IOException e){
    e.printStackTrace();
}
```

### 另外还有：throws /throw（抛出异常，不是捕获）

```
// throws：声明这个方法可能抛出异常，交给调用者处理
public static void test() throws IOException {
    throw new IOException("手动抛出异常");
}
```

## 一句话总结

- `try` 是必须的；
- `catch` 和 `finally` **至少要有一个**；
- 不是必须同时写 catch + finally。

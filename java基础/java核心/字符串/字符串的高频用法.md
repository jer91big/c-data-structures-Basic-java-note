## 1. 字符串比较与判断

| **方法**                             | **功能描述**     | **示例/特点**                                            |
| ---------------------------------- | ------------ | ---------------------------------------------------- |
| **`equals(Object obj)`**           | 精确比较内容是否相同   | `str.equals("hello")` （区分大小写）                        |
| **`equalsIgnoreCase(String str)`** | 忽略大小写比较内容    | `"ABC".equalsIgnoreCase("abc")` $\rightarrow$ `true` |
| **`startsWith(String prefix)`**    | 判断是否以指定前缀开头  | `str.startsWith("http")`                             |
| **`endsWith(String suffix)`**      | 判断是否以指定后缀结尾  | `str.endsWith(".png")`                               |
| **`contains(CharSequence s)`**     | 判断是否包含子串     | `str.contains("java")`                               |
| **`isEmpty()`**                    | 判断字符串长度是否为 0 | `"".isEmpty()` $\rightarrow$ `true`                  |

## 2. 查找与获取

| **方法**                             | **功能描述**               | **示例/特点**                             |
| ---------------------------------- | ---------------------- | ------------------------------------- |
| **`length()`**                     | 获取字符串字符长度              | `"hello".length()` $\rightarrow$ `5`  |
| **`charAt(int index)`**            | 获取指定索引（下标）处的字符         | `"abc".charAt(1)` $\rightarrow$ `'b'` |
| **`indexOf(int ch / String str)`** | 查找指定字符或子串**第一次**出现的索引  | 未找到返回 `-1`                            |
| **`lastIndexOf(...)`**             | 查找指定字符或子串**最后一次**出现的索引 | 未找到返回 `-1`                            |

## 3. 截取与替换

| **方法**                              | **功能描述**       | **示例/特点**                                       |
| ----------------------------------- | -------------- | ----------------------------------------------- |
| **`substring(int beginIndex)`**     | 从指定位置截取到末尾     | `"hello".substring(2)` $\rightarrow$ `"llo"`    |
| **`substring(int begin, int end)`** | 截取指定范围的子串      | **左闭右开**：包含 `begin`，不含 `end`                    |
| **`replace(target, replacement)`**  | 替换所有匹配的字符或子字符串 | `"abc".replace("a", "x")` $\rightarrow$ `"xbc"` |

## 4. 转换与修剪

|**方法**|**功能描述**|**示例/特点**|
|---|---|---|
|**`toCharArray()`**|将字符串转换为新的字符数组（`char[]`）|常用于遍历或逐字操作|
|**`toUpperCase()`**|全部转换为大写字母|`"abc"` $\rightarrow$ `"ABC"`|
|**`toLowerCase()`**|全部转换为小写字母|`"ABC"` $\rightarrow$ `"abc"`|
|**`trim()`**|去除字符串**首尾**的空白字符|不会去除字符串中间的空格|

## ArrayList 常见方法速查表

|**分类**|**方法签名**|**功能说明**|**返回值 / 特点**|
|---|---|---|---|
|**添加数据**|`boolean add(E e)`|将元素添加至集合**末尾**|返回 `true`|
||`void add(int index, E e)`|在指定**索引位置**插入元素|无返回值，原索引及后续元素后移|
|**删除数据**|`boolean remove(Object o)`|移除指定的**元素**（首个匹配项）|成功删除返回 `true`，未找到返回 `false`|
||`E remove(int index)`|移除指定**索引位置**的元素|返回被删除的元素|
|**修改数据**|`E set(int index, E e)`|将指定索引位置的数据**修改**为新元素|返回被覆盖的**旧元素**|
|**获取与查询**|`E get(int index)`|获取指定索引位置的数据|返回对应位置的元素|
||`int size()`|获取集合中元素的**数量（长度）**|返回整型长度|

我们把这些方法分成四大类，边看动画边记，绝对忘不掉：

### 🚌 1. 【上车系列】—— 往车里塞人

- **`add(E e)`（排队上车）**：
    
    - **动画展示**：新来的乘客乖乖走到大巴车的最后一排，找到第一个空位坐下。
        
    - **代码**：`bus.add("张三");` // 张三坐在了0号位
        
- **`add(int index, E e)`（强行插队）**：
    
    - **动画展示**：一个霸道的乘客指着 1号座位说：“我就要坐这！”于是，原本坐在 1号位以及后面的所有乘客，只能唉声叹气地站起来，往后挪一个座位，把位置让给他。**（极度耗费性能，要尽量少用！）**
        
    - **代码**：`bus.add(1, "霸王龙");`
        

### 🥾 2. 【下车系列】—— 把人踢下车

- **`remove(int index)`（按座位号踢人）**：
    
    - **动画展示**：售票员大喊：“3号座位的乘客，给我下车！”3号下车后，后面4号、5号的乘客必须立刻往前挪，补齐空位。
        
    - **代码**：`bus.remove(3);`
        
- **`remove(Object o)`（按名字找人踢）**：
    
    - **动画展示**：售票员拿着通缉令喊：“谁叫李四？滚下车！”注意：如果车上有两个“李四”，**只有坐在最前面的那个李四会被踢下去**，后面的李四逃过一劫。（底层是用的 `equals()` 挨个对比）
        
    - **代码**：`bus.remove("李四");`
        
- **`clear()`（终点站清场）**：
    
    - **动画展示**：到终点站了，大巴车底盘一打开，所有乘客瞬间掉下车。车子瞬间空了，但**大巴车的外壳和座位还在**（容量没变，只是清空了数据）。
        
    - **代码**：`bus.clear();`
        

### 🔎 3. 【查岗查人系列】—— 列车员的日常

- **`get(int index)`（精准查岗）**：
    
    - **动画展示**：列车员走到 5号座位前看了一眼：“哦，原来你坐这儿啊。”**（速度极快，不管车里有1万人还是10万人，瞬间就能找到，这是 ArrayList 最大的优点！）**
        
    - **代码**：`String person = bus.get(5);`
        
- **`size()`（清点人数）**：
    
    - **动画展示**：数一数现在车上坐了多少个“真实乘客”。注意，这不是问大巴车能装多少人（容量capacity），而是问**实际坐了多少人**。
        
    - **代码**：`int count = bus.size();`
        
- **`contains(Object o)`（大喇叭寻人）**：
    
    - **动画展示**：列车员拿大喇叭喊：“车上有没有叫‘王五’的？”如果有，返回 `true`，没有返回 `false`。
        
    - **代码**：`boolean hasWang = bus.contains("王五");`
        
- **`isEmpty()`（看车空不空）**：
    
    - **动画展示**：探头看一眼车厢，如果里面一个人都没有（`size == 0`），返回 `true`。
        
    - **代码**：`boolean empty = bus.isEmpty();`
        

### 🔄 4. 【狸猫换太子系列】

- **`set(int index, E e)`（换座位/替换）**：
    
    - **动画展示**：走到 2号座位，一把将原来的乘客拽下车丢掉，然后把一个新乘客按在 2号座位上。整个过程没有任何人需要挪动屁股，只是单纯的替换！
        
    - **代码**：`bus.set(2, "新来的");`
        

**🔥 大巴老司机的一句话总结：** 用 ArrayList 的口诀就是：**“找人换人非常快（get/set），插队删人累得慌（add插队/remove），默认扩容一点五（1.5倍），排队上车最稳当（普通add）！**
### 💡 关键使用注意点

1. **增/删/改的索引边界**：使用 `add(index, e)`、`remove(index)`、`set(index, e)` 和 `get(index)` 时，索引必须在合法范围内（`0` 到 `size() - 1`，其中插入操作允许 `index == size()`），否则会抛出 `IndexOutOfBoundsException`（数组越界异常）。
    
2. **`remove` 的重载陷阱**：
    
    - 如果 `ArrayList<Integer>` 存储的是整数，调用 `remove(1)` 默认会优先匹配 **根据索引删除** `remove(int index)`。
        
    - 如果想根据**值**删除数值 `1`，需要手动包装：`list.remove(Integer.valueOf(1))`。
        
3. **与数组 `length` 的区别**：
    
    - 数组获取长度用属性：`arr.length`
        
    - 字符串获取长度用方法：`str.length()`
        
    - `ArrayList` 获取长度用方法：`list.size()`

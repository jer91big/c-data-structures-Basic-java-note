## 🧬继承 (Inheritance) —— 拒绝重复造轮子

**一句话核心：儿子继承老子，不仅能全盘接收，还能青出于蓝。**

### 1. 为什么要继承？（大聪明 vs 老实人）

假设现在《王者荣耀》要开发三个新英雄：战士、法师、射手。

- **老实人（不按套路出牌）：** 写三个类，每个类里都狂敲一遍 `name`、`hp`、`move()`（移动）、`recall()`（回城）。累得疯狂掉头发。
    
- **大聪明（用继承）：** 先写一个公共的 **`Hero`（父类）**，把共用的名字、血量、回城写好。然后让战士、法师、射手去“认爹”。
    

### 2. 怎么“认爹”？ —— `extends` 关键字

在 Java 里，认爹只需要一个词：`extends`（延伸/扩展）。

Java

```
// 这是父类（老子）：通用模板
public class Hero {
    String name;
    int hp;

    public void recall() {
        System.out.println("按B键回城中...咻~");
    }
}

// 这是子类（儿子）：射手
public class Shooter extends Hero {
    // name, hp, recall() 已经隐形存在了，不用再写！
    
    int range; // 射手独有的属性：射程

    // 射手独有的行为
    public void shoot() {
        System.out.println(name + " 正在远程biubiubiu！");
    }
}
```

> **动画演示：**
> 
> 1. 电脑读取到 `extends Hero`。
>     
> 2. 瞬间，一个虚拟的传送门打开。
>     
> 3. `Hero` 里面的 `name`、`hp`、`recall()` 像发光的数据流一样，直接“复制粘贴”倾注到了 `Shooter` 的体内。
>     
> 4. `Shooter` 睁开眼睛，不仅会回城，还会了自己专属的 `shoot()`。
>     

### 3. “我不服老规矩！” —— 方法重写 (Override)

有时候，父类给的技能，子类觉得太土了，想自己改。这就是**方法重写**。

比如，普通的 `Hero` 走路是用腿跑，但**大乔**（辅助类）是飘在空中的。

Java

```
public class Support extends Hero {
    
    // 覆盖掉老子的 move() 方法！
    @Override // 这个注解是告诉编译器：我在重写父类方法！
    public void move() {
        System.out.println("大乔脚不沾地，飘着移动~");
    }
}
```

**规则：** 方法名和参数必须和父类一模一样，但大括号 `{}` 里面的内容你自己说了算。

### 4. 遇到困难找爸爸 —— `super` 关键字

如果在子类里，你突然想借用一下父类的东西，就大喊一声：`super`。

- `super.name` = 拿父类的属性。
    
- `super.recall()` = 执行父类的回城。
### 5.总结
- 1.java只能单继承，不支持多继承，但是支持多层继承
- 2.直接继承的父类叫直接父类，简洁继承的爷爷叫做间接父类
- 3.java中所有的类都是直接或者间接继承于object类

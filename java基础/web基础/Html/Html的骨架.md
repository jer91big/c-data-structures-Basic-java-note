## 🏛️ 第一课：HTML 骨架搭建物语 —— 搭建新闻的“毛坯房”

### 1. 什么是 HTML？（用动画般的视角想象）

如果把网页比作一个人，**HTML 就是他的骨骼**。它不管美不美观，只负责决定：哪里是脑袋（标题），哪里是躯干（正文），哪里是衣服口袋（小区块）。

HTML 是由一个个“标签”（Tags）组成的，它们通常成对出现，像一双双热情拥抱的手：`<标签名> 内容 </标签名>`。

### 2. 央视新闻的“骨架”长什么样？

闭上眼睛想象一篇央视新闻网页：

1. 最上面是一个醒目的大标题。
    
2. 标题下方有一行小字：`央视网消息 | 2026年10月27日`（我们叫它“元信息条”）。
    
3. 接着是核心导语或正文段落。
    

让我们用代码把这个骨架“变”出来：

HTML

```
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>央视新闻排版模拟</title>
</head>
<body>

    <!-- 这是一个区块：新闻容器 -->
    <div class="news-container">
        
        <!-- 新闻主标题 -->
        <h1>科技创新赋能高质量发展：数字未来正在走来</h1>
        
        <!-- 新闻来源与时间栏 -->
        <div class="news-info">
            <span class="source">央视网</span>
            <span class="date">2026年10月27日 12:00</span>
        </div>
        
        <!-- 新闻正文段落 -->
        <p>央视网消息：金秋十月，神州大地处处洋溢着蓬勃的创新活力。在数字经济与实体经济深度融合的浪潮下，新质生产力正成为推动经济社会高质量发展的强劲引擎。</p>
        
        <p>专家指出，随着前沿技术的不断突破，未来产业布局正在加速推进，为人民群众创造了更加智能、便捷的高品质生活。</p>

    </div>

</body>
</html>
```

### 🔍 逐行代码拆解（老师的慢动作特写）

- `<!DOCTYPE html>`：这是给浏览器的“通行证”，告诉浏览器：“嘿！这是一个现代化的标准网页，请用最新的 HTML5 规则来解析我！”
    
- `<html> ... </html>`：整个网页的**宇宙边界**，所有的内容都在这个大城堡里。
    
- `<head> ... </head>`：网页的**大脑幕后**。这里放着网页的标题、编码格式（UTF-8 保证中文不乱码），网页用户虽然看不见，但浏览器全靠它来理解网页。
    
- `<body> ... <body>`：网页的**舞台前台**！你在屏幕上看到的文字、图片、按钮，全部都要装在这个大盒子里。
    
- `<h1> ... </h1>`：最强壮、最醒目的**一级标题**。在央视新闻里，它就是那条重磅头条大标题。
    
- `<div class="...">`：一个神奇的“隐形收纳盒”。`div` 本身没有任何形状，但它可以把相关的元素（比如把来源和时间）打包在一起，方便我们以后用 CSS 统一管理。
    
- `<p> ... </p>`：**段落标签**（Paragraph）。每一段新闻文字都躺在自己的 `<p>` 怀抱里，浏览器会自动在段落上下空出舒适的距离。

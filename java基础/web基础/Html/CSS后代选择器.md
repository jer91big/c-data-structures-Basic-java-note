# CSS 后代选择器

今天只学习一个知识点：如何选中某个区域内部的指定元素。

## 一、先看你的代码

你的代码中有这样一段：

```
.news-content p {
    margin: 0 0 1.1em;
    text-indent: 2em;
}
```

你可能会想：这里明明有两个东西，`.news-content` 和 `p`，它们为什么能放在一起？

别急，我们把它拆开。

## 二、想象新闻网页是一栋大楼

### 新闻正文区域

news-content

这个区域里面有多个段落

第一段新闻

HTML：`p`

第二段新闻

HTML：`p`

我们想给这栋大楼里的所有新闻段落设置样式，而不是影响页面其他区域的段落。

这时就轮到后代选择器出场了。

## 三、认识这个空格

看下面的 CSS：

```
.news-content p {
    text-indent: 2em;
}
```

这里最重要的是两个选择器之间的一个空格：

```
.news-content p
```

浏览器会这样理解：

1. 先找到带有 `news-content` 类名的元素。
    
2. 再找到这个元素内部所有的 `p` 元素。
    
3. 给找到的段落应用首行缩进样式。
    

这就叫后代选择器。

你可以把它想象成编辑部主任下达命令：

“只要是新闻正文区域里面的段落，全部执行这个排版规则！”

### 再对比一下

只选择新闻正文区域

```
.news-content {
    color: #333;
}
```

选中的是具有 `news-content` 类名的元素本身。

选择新闻正文区域中的段落

```
.news-content p {
    text-indent: 2em;
}
```

选中的是 `.news-content` 内部的 `p` 元素。

注意：后代不一定是直接子元素。只要 `p` 位于 `.news-content` 内部，无论中间还嵌套了几层元素，都可能被这个选择器选中。

今天只记住一个规律：两个选择器之间有空格，表示选择前一个元素内部符合后一个选择器的元素。
